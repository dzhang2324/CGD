# Preserved analysis inputs

These files are unchanged copies of the original saved inputs. Do not edit
them in place.

| Path | Role |
| --- | --- |
| `raw/Medicaid_Spending_by_Drug_2021.csv` | Source Medicaid spending records containing annual measures for 2017–2021 |
| `raw/costplus.csv` | Saved 442-row Cost Plus price snapshot |
| `reference/med_panel.csv` | Historical reshaped Medicaid panel, used only to audit the new reconstruction |
| `documentation/nadacdatadefinitions.pdf` | Historical NADAC data dictionary; not an input to the current regressions |

These files previously lived under `CGPP Data/`. The relocation manifest in
`archive/relocation-manifest.json` records their original paths and hashes.
Each analysis run also writes input hashes to `analysis/output/audit.json`.
Git attributes preserve the original file bytes and line endings on checkout.

The current pipeline reconstructs the Medicaid panel from the source CSV.
The historical panel replaced missing annual values with zeros; the new
panel preserves missingness and checks the older transformation separately.
Keeping the reference panel allows that comparison to remain reproducible.

The original NADAC CSV is unavailable. The data dictionary does not replace it.
The saved Medicaid and Cost Plus inputs are sufficient to reproduce the
regressions generated by `python -m analysis.run`.
