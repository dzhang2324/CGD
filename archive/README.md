# Historical material

This directory preserves the original code, drafts, and revision records.
Use `analysis/` for the current Python pipeline and `Paper/` or `ShortPaper/`
for the current manuscripts.

| Directory | Former location and contents |
| --- | --- |
| `code/` | Root-level Jupyter notebooks and R Markdown analysis |
| `manuscripts/` | Three root-level historical PDFs |
| `source/` | Original `Competition_and_Generic_Drugs.zip` |
| `docs/` | Previous `docs/` tree: review notes, proposed replacements, literature checks, and table previews |
| `checkpoints/full-paper/` | Previous `Paper/checkpoints/` PDF snapshots |
| `figures/` | Unused full-paper figures formerly under `Paper/` |

`docs/repository-readme-before-cleanup.md` preserves the previous root README.
Historical short-paper snapshots remain inside
`ShortPaper/archive/`; the latest figure-placement checkpoint remains in
`ShortPaper/checkpoints/`.

The archived files have not been rewritten. Dates, paths, status statements,
and proposed edits refer to their original snapshots and may be superseded.
In particular, old claims that revisions are pending or that the short paper
is deferred are not current instructions.

`relocation-manifest.json` maps each relocated file to its old path and
records its SHA-256 hash. Git tag `before-repository-cleanup` preserves the
complete pre-cleanup layout.

These files remain tracked, including historical reviewer notes. Moving them
here does not remove them from the repository or its Git history.
